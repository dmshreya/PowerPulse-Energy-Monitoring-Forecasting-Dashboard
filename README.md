Features
- Real-time data fetching (Open-Meteo API)
- Energy consumption simulation
- Interactive dashboard with Plotly
- Peak, average, and lowest usage insights
- ARIMA-based forecasting
- Smart optimization recommendations
- Highlighted key insights in tables


How It Works
 Fetches weather data (temperature)
 Converts it into simulated energy consumption
 Analyzes patterns (peak, average, low)
 Predicts future usage using ARIMA
 Generates optimization suggestions
